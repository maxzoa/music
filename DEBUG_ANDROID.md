# Подробная инструкция по отладке Android

## Шаг 1: Подготовка телефона

1. **Включите режим разработчика:**
   - Откройте `Настройки` → `О телефоне` → `Информация о ПО`
   - Нажмите 7 раз на `Номер сборки`
   - Появится сообщение "Вы стали разработчиком"

2. **Включите отладку по USB:**
   - `Настройки` → `Параметры разработчика`
   - Включите `Отладка по USB`
   - Включите `Установка через USB` (если есть)

3. **Подключите телефон к компьютеру:**
   - Используйте USB кабель
   - На телефоне выберите режим `Передача файлов` или `PTP`
   - Разрешите отладку (появится запрос на телефоне)

## Шаг 2: Настройка на компьютере

1. **Откройте Chrome на компьютере:**
   - Введите в адресной строке: `chrome://inspect`
   - Или `chrome://inspect/#devices`

2. **Проверьте настройки:**
   - Поставьте галочку `Discover USB devices`
   - Поставьте галочку `Discover network targets` (опционально)

3. **Подождите обнаружения:**
   - Ваш телефон должен появиться в списке устройств
   - Если не появился - переподключите USB

## Шаг 3: Отладка приложения

1. **Откройте приложение на телефоне:**
   - Зайдите в Chrome на телефоне
   - Откройте ваше приложение: https://melody-guesser-2.preview.emergentagent.com

2. **На компьютере в chrome://inspect:**
   - Найдите вкладку с вашим приложением
   - Нажмите `inspect` под этой вкладкой
   - Откроется DevTools для мобильной страницы

3. **Смотрите консоль:**
   - Вкладка `Console` - все логи
   - Вкладка `Network` - запросы к серверу
   - Вкладка `Elements` - HTML страницы

## Шаг 4: Что проверить в логах

**При старте записи должно быть:**
```
Starting recording...
Requesting media with constraints: {...}
✓ Media stream obtained
Using mime type: audio/webm;codecs=opus
MediaRecorder state: recording
Chunk 1: XXXX bytes
Chunk 2: XXXX bytes
...
```

**При остановке записи:**
```
Max recording time reached, stopping...
Stopping recording...
Recording stopped. Total chunks: 15
Total audio size: XXXXX bytes from 15 chunks
✓ Vibration: Recording stopped, starting recognition
```

**При отправке:**
```
Recognizing audio blob: XXXXX bytes, type: audio/webm
Detected Android - attempting to convert to WAV
Converted to WAV: XXXXX bytes
```

## Шаг 5: Типичные проблемы

### Проблема: "Файл слишком мал"
**Лог показывает:** `Total audio size: 0 bytes` или `< 10000 bytes`
**Причина:** MediaRecorder не записывает данные
**Решение:**
- Проверьте разрешения микрофона в Chrome
- Настройки → Конфиденциальность → Микрофон → Chrome → Разрешить

### Проблема: "Decode error"
**Лог показывает:** Большой размер файла, но ошибка конвертации
**Причина:** WebM формат не декодируется на устройстве
**Решение:** Будем упрощать конвертацию

### Проблема: "No result"
**Лог показывает:** Файл отправлен, но ACRCloud не нашел
**Причина:** Качество записи или распознавание
**Решение:** 
- Записывайте ближе к источнику звука
- Уберите фоновый шум
- Попробуйте популярную песню

## Шаг 6: Как сделать скриншот логов

1. В DevTools на вкладке Console
2. Правой кнопкой → `Save as...`
3. Или сделайте скриншот и отправьте
