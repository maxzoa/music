# ПОДРОБНАЯ ПОШАГОВАЯ ИНСТРУКЦИЯ

## ШАГ 1: На телефоне должен появиться запрос

**СЕЙЧАС на вашем телефоне должен появиться всплывающий запрос:**

```
Разрешить отладку по USB?
Отпечаток ключа RSA компьютера:
XX:XX:XX:XX...

[Запретить]  [Разрешить]
```

**ДЕЙСТВИЕ:** Нажмите кнопку **"РАЗРЕШИТЬ"** (или "Allow", "Разрешить")

⚠️ **ВАЖНО:** Поставьте галочку "Всегда разрешать с этого компьютера" чтобы не спрашивало каждый раз

---

## Если запрос НЕ ПОЯВИЛСЯ:

### Вариант А: Отключите и подключите USB снова

1. Выдерните USB кабель из телефона
2. Подождите 3 секунды
3. Вставьте USB кабель обратно
4. На телефоне должен появиться запрос

### Вариант Б: Измените режим USB

1. На телефоне опустите шторку уведомлений (свайп сверху вниз)
2. Найдите уведомление "USB подключен" или "Зарядка по USB"
3. Нажмите на это уведомление
4. Выберите **"Передача файлов"** (File Transfer / MTP)
5. Должен появиться запрос на отладку

### Вариант В: Сбросьте разрешения отладки

**На телефоне:**
1. Откройте **Настройки**
2. Найдите **"Параметры разработчика"** (Developer Options)
3. Прокрутите вниз до **"Отозвать разрешения для отладки по USB"**
4. Нажмите эту кнопку
5. Отключите USB кабель
6. Подключите USB кабель снова
7. Должен появиться запрос

## ШАГ 2: После принятия отладки

**На компьютере в Chrome (chrome://inspect):**

Вместо "Offline" должно появиться:
```
MIBOX3 #192.168.8.114
  
  [Список открытых вкладок Chrome на телефоне]
  
  https://songspy-1.preview.emergentagent.com
  [inspect] [focus tab] [close]
```

**ДЕЙСТВИЕ:** Нажмите синюю ссылку **"inspect"** рядом с вашим приложением

---

## ШАГ 3: Откроется окно DevTools

После нажатия "inspect" откроется **новое окно** с инструментами разработчика.

В этом окне будет несколько вкладок сверху:
- Elements
- Console ← **ВАМ СЮДА**
- Sources
- Network
- и другие...

**ДЕЙСТВИЕ:** Кликните на вкладку **"Console"**

---

## ШАГ 4: Используйте приложение и смотрите логи

1. **В окне DevTools** оставьте открытой вкладку Console
2. **На телефоне** нажмите красную кнопку записи
3. **В Console** появятся логи:
   ```
   Starting recording...
   ✓ Vibration: Recording started
   Requesting media with constraints: ...
   ✓ Media stream obtained
   Using mime type: audio/webm;codecs=opus
   Starting MediaRecorder...
   MediaRecorder state: recording
   Chunk 1: 12345 bytes
   Chunk 2: 12345 bytes
   ...
   ```

4. **Дождитесь окончания записи** (15 секунд)
5. **Смотрите что появится дальше** в Console
6. **Сделайте скриншот всех логов**

## Что если всё равно не работает?

### Проверка 1: USB кабель
- Используйте **оригинальный** USB кабель
- Кабель должен поддерживать передачу данных (не только зарядку)

### Проверка 2: USB порт
- Попробуйте другой USB порт на компьютере
- Используйте USB порт напрямую (не через USB-hub)

### Проверка 3: Драйверы
Если у вас Windows, может понадобиться установить драйверы:
1. Найдите в Google: "Xiaomi USB Driver" или "ADB Driver"
2. Скачайте и установите
3. Перезагрузите компьютер
4. Попробуйте подключить снова

## БЫСТРАЯ ДИАГНОСТИКА

**Выполните эти команды на компьютере:**

### Для Windows:
Откройте командную строку (Win+R → cmd) и введите:
```
adb devices
```

### Для Mac/Linux:
Откройте терминал и введите:
```
adb devices
```

**Должно показать:**
```
List of devices attached
192168008114    device
```

Если показывает `unauthorized` - значит не приняли отладку на телефоне
Если не показывает ничего - проблема с USB или драйверами
