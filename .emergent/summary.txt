**what currently exists?**
A full-stack web application with a React frontend and a FastAPI backend. The application is designed to be used on mobile devices, particularly Android. It uses the Web Audio API () to record audio from the microphone for 15 seconds. The recorded audio is then sent to the backend, which uses the ACRCloud API to perform music recognition. The backend processes the result to extract the first three letters of the artist's name and converts them into a sequence of vibrations based on a predefined alphabet grouping. The frontend then executes this vibration pattern. The UI is minimalistic with a black background, a custom logo, and a large button that also serves as a progress indicator during recognition.
