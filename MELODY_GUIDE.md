# Угадай Мелодию - Читерское приложение для квизов

Веб-приложение для Android, которое распознает музыку и дает подсказки через вибросигналы.

## Возможности

- 🎤 **Запись аудио** через микрофон (Web Audio API)
- 🎵 **Распознавание музыки** через AudD API
- 📱 **Вибросигналы** для подсказок:
  - 1 вибро = английское название
  - 2 вибро = русское название
  - Побуквенное кодирование: группа букв → позиция в группе
- 📊 **История** распознаваний в MongoDB
- 🎨 **Адаптивный дизайн** для мобильных устройств

## Как использовать

1. Откройте приложение на Android в Chrome/Firefox
2. Разрешите доступ к микрофону
3. Нажмите на иконку микрофона
4. Запишите 5-10 секунд музыки
5. Остановите запись
6. Получите название песни и вибросигналы с подсказкой

## Технологии

- **Frontend**: React, Web Audio API, Vibration API, Tailwind CSS
- **Backend**: FastAPI, Python
- **Database**: MongoDB
- **API**: AudD Music Recognition API

## Алгоритм вибросигналов

### Индикатор языка
- 1 короткий вибро (200мс) = английский
- 2 коротких вибро = русский

### Побуквенное кодирование
Алфавит разделен на группы по 5 букв:

**Русский** (7 групп):
1. А-Д
2. Е-Й (включая Ё)
3. Й-Н
4. О-Т
5. У-Ч
6. Ш-Ь
7. Э-Я

**Английский** (6 групп):
1. A-E
2. F-J
3. K-O
4. P-T
5. U-Y
6. Z

Каждая буква кодируется двумя сигналами:
1. Номер группы (количество коротких вибро)
2. Пауза 500мс
3. Номер буквы в группе (количество коротких вибро)
4. Пауза 1000мс перед следующей буквой

**Пример**: Буква "К" (русский)
- 3 вибро (группа 3: Й-Н)
- пауза 500мс
- 2 вибро (2-я буква в группе: К)

## Настройка

### Backend (.env)
```
AUDD_API_TOKEN=your_audd_token_here
MONGO_URL=mongodb://localhost:27017
DB_NAME=melody_guesser
```

### Получение AudD токена
1. Зарегистрируйтесь на https://audd.io
2. Получите бесплатный API токен (300 запросов/месяц)
3. Добавьте токен в `/app/backend/.env`
4. Перезапустите backend: `sudo supervisorctl restart backend`

## API Endpoints

- `GET /api/` - проверка API
- `POST /api/recognize` - распознавание музыки (multipart/form-data)
- `GET /api/status` - история распознаваний
- `POST /api/status` - создать запись статуса

## Ограничения

- Web Audio API требует HTTPS или localhost
- Vibration API работает только на Android (Chrome, Firefox)
- AudD API: 300 бесплатных запросов/месяц
- Максимальный размер файла: 10MB
- Поддерживаемые форматы: MP3, WAV, WebM, OGG
